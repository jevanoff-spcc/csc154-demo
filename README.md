# csc154-demo
Test space for CSC 154 development


## How to run

Import `tracker.py` in Python and call `add_task("Buy milk")`.

## Known limitations

- Only `add_task` is built. Listing, completing, editing and deleting tasks are not built yet.
- Tasks are kept in memory, so they are lost when the program stops.
- There is no command-line interface yet. Run it by importing `tracker.py`.
